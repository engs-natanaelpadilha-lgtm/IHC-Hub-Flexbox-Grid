O que é CSS Grid?

CSS Grid é um sistema de layout bidimensional que permite organizar elementos em linhas e colunas. Ele facilita a criação de páginas estruturadas, galerias de imagens e grades de cartões.

Principais propriedades

  • display: grid: ativa o Grid.
  • grid-template-columns: define as colunas.
  • grid-template-rows: define as linhas.
  • gap: define o espaço entre os elementos.
  • grid-column: define as colunas ocupadas por um item.
  • grid-row: define as linhas ocupadas por um item.

Quando utilizar?

O Grid é indicado para galerias, painéis, páginas com várias áreas de conteúdo e layouts que precisam organizar elementos em linhas e colunas.
