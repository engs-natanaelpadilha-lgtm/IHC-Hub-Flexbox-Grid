5. Introdução ao Flexbox

⬅ Voltar ao Hub

O que é Flexbox?

O Flexbox é uma forma de organizar os elementos de uma página. Ele permite colocar os itens em linhas ou colunas e facilita o alinhamento.

Como funciona?

Para usar o Flexbox, colocamos display: flex no elemento que contém os outros elementos.

Assim, os itens dentro dele podem ser organizados e alinhados de diferentes formas.

Principais propriedades

display: flex; ativa o Flexbox.

flex-direction: define se os itens ficam em linha ou coluna.

justify-content: organiza os itens no eixo principal.

align-items: alinha os itens no outro eixo.

Onde podemos usar?
